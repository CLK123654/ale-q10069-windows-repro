# 合作方Webhook重放队列

本仓库保存QID10069的最终任务材料和独立运行入口。artifacts目录含四个最终附件，task目录含题面正文，verification目录负责从附件重新构建Reference并检查业务结果。

在Node.js24环境执行npm run verify。程序会在两个带中文和空格的空目录运行完成版源码，核对业务输入未被改动，并按结构比较三份交付物。随后修改端点退避规则，确认E009的投递时刻随输入变化；删除合作方公钥文件时，进程应返回非零且不留下交付物。

GitHub工作流使用windows-2025和PowerShell。运行证据作为工作流附件保存，包含当前提交、运行编号、软件版本、四附件SHA-256、退出码和结构化语义摘要。
